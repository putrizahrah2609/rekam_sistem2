# Klinik Sehat - Sistem Rekam Medis

Aplikasi rekam medis rawat jalan (pendaftaran, perawat, dokter SOAP, apotek dan kasir, stok obat, laporan).

Satu file `index.html`, tanpa proses build. Data tersimpan di localStorage browser.

Akun contoh: admin/admin123, daftar/daftar123, perawat/perawat123, dokter/dokter123, apotek/apotek123.
